# Platform Capabilities

This document describes the planned platform capabilities of GameClan.hub.

**Status:** These are planned capabilities. None are implemented in the bootstrap phase.

---

## Identity and Profiles

| Feature | Description |
|---|---|
| Authentication | Register, log in, manage account |
| Profiles | Public player profile: display name, avatar, bio, stats |
| Account settings | Email, password, notification preferences |

## Social

| Feature | Description |
|---|---|
| Friends | Send, accept, decline friend requests |
| Presence | See when friends are online or in a game |
| Chat | Persistent conversations with friends or groups |
| Blocking | Block users from contacting or matching with you |

## Discovery and Play

| Feature | Description |
|---|---|
| Game discovery | Browse available games, view descriptions and rules |
| Matchmaking | Find opponents automatically |
| Private rooms | Create or join a game by code or invite |
| Computer opponents | Play solo against the platform AI |
| Solo play | Some games support single-player modes |

## Progression

| Feature | Description |
|---|---|
| XP and levels | Earn experience points through play; advance levels |
| Achievements | Unlock achievements for accomplishments in any game |
| Challenges | Time-limited or goal-based challenges |
| Player statistics | Per-game and aggregate play history |

## Competition

| Feature | Description |
|---|---|
| Leaderboards | Global and per-game rankings |
| Season rankings | Periodic competitive seasons (future) |

## Notifications

| Feature | Description |
|---|---|
| In-app notifications | Friend requests, match invites, achievements, challenges |
| Push notifications | Mobile push notifications for key events (future) |

## Moderation

| Feature | Description |
|---|---|
| Reporting | Report players for bad behaviour |
| Blocking | Block unwanted contact |
| Admin tools | Operator moderation interface in the admin application |

---

## Implementation Priority

Capabilities will be implemented incrementally, starting with the core platform (authentication, profiles, matchmaking) before adding progression and social features. Refer to [`roadmap.md`](roadmap.md) for phasing.
