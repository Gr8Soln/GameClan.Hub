# @gameclan/api-client

Shared API client library for the GameClan.hub platform.

## Purpose

Provides a consistent interface for consuming the GameClan server REST API and WebSocket connection across all clients (web, mobile, admin).

## Status

> **Planned.** This package is not yet implemented. It will be developed once the server API is established.

## Planned Scope

- HTTP request helpers with type-safe request/response shapes (using `@gameclan/contracts`)
- WebSocket connection management
- Shared error handling conventions

## Usage

> Planned.

```typescript
import { GameClanClient } from '@gameclan/api-client';
```
